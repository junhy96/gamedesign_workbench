도구 열기

회피 윈도우

타격 [h0, h1]을 무적으로 덮는 입력 구간의 길이 = 무적 − 판정 + 1. 0 이하면 구르기로 피할 수 없다고 판정하고, 연계 중 직전 회피 후딜로 줄어든 윈도우도 계산합니다.

  • 01윈도우 = 무적 − 판정 + 1
  • 02연계 중 실제 윈도우
  • 0330 / 60 / 120fps

반응·암기 판정과 수정 제안

식별 시점 + 반응 시간 + 입력·화면 지연이 마지막 유효 입력보다 늦으면 암기 패턴입니다. 몇 프레임 늦는지, 선딜을 얼마나 늘리면 되는지까지 문장으로 알려 줍니다.

  • 01식별 + 반응 + 지연
  • 02≤ 마지막 유효 입력
  • 03선딜 수정 제안

최적 입력 계획

타격을 무리로 나눠 회피 한 번이 무리 전체를 덮게 하고, 다시 행동 가능한 가장 이른 프레임을 상태로 둔 동적 계획법으로 최적 입력을 찾습니다. 반응형으로는 못 피하지만 최적 입력으로는 피하는 타격을 “선입력 강제”로 표시합니다.

  • 01동적 계획법
  • 02선입력 강제 감지
  • 03반격 가능 횟수

기술 일람 양식 PowerPoint

패턴 타임라인 → 공격별 1장(공격 구간 확대) → 패턴별 판정 표 → 검증 결과를 편집 가능한 도형으로 저장합니다. 애니메이션 띠는 캡처를 붙여 넣는 자리로 비워 둡니다.

  • 01보라 헤더 바 · 정보 표
  • 02초 단위 축과 둥근 막대
  • 03편집 가능한 도형
계산과 검증

어떻게 계산하고, 어떻게 확인했나

계산 방법

  • 회피 입력 구간 = [판정 끝 − 선딜 − 무적 + 1, 판정 시작 − 선딜]
  • 반응 가능 = 식별 시점 + 반응 시간 + 입력 지연 ≤ 마지막 유효 입력
  • 최적 입력 계획 = 타격 무리별 회피 1회, 다시 행동 가능한 가장 이른 프레임을 상태로
  • 반격 여유 = 회피 끝 ~ 다음 타격을 피하기 위한 마지막 입력

검증

  • 회피 윈도우 공식 = 모든 입력 프레임 직접 대입 (조합 1,200가지)
  • 최적 입력 계획 = 모든 입력 조합 브루트포스 (무작위 연계 1,000개)
  • 기본 템플릿 손계산 값, 선입력 강제 감지, 한 번에 여러 타격 회피
11이 도구의 자동 테스트 (전체 111개)
판단 사례

브루트포스 테스트가 찾아낸 계산 실수

처음에는 가장 이른 입력만 고르는 탐욕법을 썼습니다. 무작위 연계 1,000개를 모든 입력 조합과 비교하는 테스트가, 한 번의 회피로 두 타격을 덮는 경우를 탐욕법이 놓친다는 것을 찾아냈고, 동적 계획법으로 바꿨습니다.
