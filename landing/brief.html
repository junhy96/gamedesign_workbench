도구 열기

스냅샷

헤더의 “스냅샷”에서 모든 탭 설정을 한 번에 저장하고, 나중에 지금 설정과 탭별 핵심 지표를 비교하거나 되돌립니다. 프로젝트 파일로 팀과 같은 설정을 나눕니다.

  • 01모든 탭 한 번에 저장
  • 02지표 비교 · 되돌리기
  • 03프로젝트 파일

목표 판정

지표마다 ≤ 또는 ≥ 목표를 넣으면 통과·미달을 표시하고, 미달 목록을 요약에 모읍니다. 퍼센트 지표는 퍼센트 단위로 넣습니다.

  • 01≤ · ≥ 목표
  • 02✓ 통과 / ✗ 미달
  • 03미달 목록 요약

메모와 PDF

결론·근거·리스크·결정 요청을 적고 “PDF로 저장(인쇄)”을 누르면, 입력칸과 헤더를 숨기고 값만 남긴 한 장짜리 문서가 됩니다. 비워 둔 메모는 나오지 않습니다.

  • 01결론 · 근거
  • 02리스크 · 결정 요청
  • 03인쇄용 화면

되돌리기

헤더의 ↶ ↷ 또는 Ctrl+Z · Ctrl+Shift+Z로 모든 탭에서 같은 방식으로 되돌립니다. 탭마다 최대 50단계입니다.

  • 01모든 탭 공통
  • 02탭마다 50단계
  • 03Ctrl+Z · Ctrl+Shift+Z
계산과 검증

어떻게 계산하고, 어떻게 확인했나

계산 방법

  • 스냅샷 = 각 탭 저장 키의 묶음, 지표는 탭의 계산 모듈을 그대로 호출
  • 목표 판정: % 지표는 % 단위로 입력
  • 검증 문장: 심각한 것부터 탭마다 4개
  • PDF = 브라우저 인쇄 (인쇄용 CSS로 값만)

검증

  • 모든 탭의 기본 설정에서 핵심 지표가 계산됨
  • 스냅샷 저장 → 설정 변경 → 비교 → 되돌리기
  • 프로젝트 파일을 다른 브라우저로 옮겨도 같은 설정·스냅샷

회의 직전 5분

고치기 전에 스냅샷을 저장하고, 수치를 바꾼 뒤 브리핑 탭에서 그 스냅샷을 기준으로 고르면 바뀐 탭과 지표별 변화가 한 장에 모입니다. 목표를 넣고 결정 요청을 적어 PDF로 저장하면 회의 자료가 됩니다.

템플릿 수치는 설계 예시이며 특정 게임의 실제 수치가 아닙니다.
