엑셀 전투 시트를 그대로 옮겨 와 깨진 참조를 찾습니다

전투 시뮬레이터가 읽는 직업·캐릭터·몬스터·스킬·효과·속성 상성·시너지 일곱 개 테이블을 편집합니다. 테이블끼리는 ID로 참조하고, 엑셀이 저장한 CSV를 그대로 불러오며, 없는 ID 참조·중복 ID·빈 필수값·범위 밖 숫자를 행과 칸에 표시합니다. 행을 더하면 시뮬레이터의 선택 목록에 바로 나타납니다.

도구 열기

검증 — 빨간 칸과 노란 칸

모든 ID를 먼저 모은 뒤 참조 칸(ClassID, 속성, 스킬·효과 목록, 페이즈 안의 스킬, 시너지 조건 값)을 하나씩 대조합니다. 빈 필수값·중복 ID·숫자 범위·선택지 밖 값은 오류, 효과가 걸리지 않는 설정은 경고로 표시하고, 오류를 누르면 그 칸으로 이동합니다.

  • 01CL_WARIOR → 직업 테이블에 없음
  • 02EF_STUNN → 효과 테이블에 없음
  • 03발동 확률 130 → 100 이하

CSV 왕복 — 엑셀 저장본 그대로

BOM, 따옴표 안 쉼표·줄바꿈, 쉼표·세미콜론·탭 구분자, 한글 머리글(체력)과 한글 선택지(탱커)를 그대로 읽습니다. 내보낼 때는 열 키와 한글 선택지로 써서 엑셀에서 바로 열립니다. 전체 또는 테이블 하나를 JSON으로도 주고받습니다.

  • 01머리글: hp 또는 체력
  • 02여러 ID: SK_A|SK_B
  • 037개 테이블 왕복 일치

ID 바꾸기와 참조

ID를 고치면 그 ID를 가리키던 다른 테이블의 칸도 함께 바뀝니다. 보스 페이즈 문자열("70=SK_FLAME|SK_SLAM; 30=…") 안의 스킬, 상성 표의 열, 같은 속성 시너지의 조건 값까지 따라갑니다.

  • 01SK_SLAM → SK_SMASH
  • 02몬스터 스킬·페이즈 함께
  • 03이미 있는 ID면 중복 오류

최종 스탯 계산 순서

① 직업 기본(Lv1) → ② 레벨 성장(성장 × (Lv − 1)) → ③ 캐릭터 보정(합: + 값 / 곱: × (1 + 값%)) → ④ 장비·버프. 전투 시뮬레이터의 대결 구성 표가 단계별 값을 그대로 보여 줍니다.

  • 01아렌: 900 → 2,640 → 2,740
  • 02달리아 공격력: 371.5 × 1.1 = 408.7
  • 03몬스터는 표의 값 그대로
계산과 검증

어떻게 계산하고, 어떻게 확인했나

계산 방법

  • 테이블 정의(열 종류: ID·문자·숫자·선택지·참·거짓·참조·여러 참조·페이즈) 하나로 편집기·검증·CSV를 함께 만듦
  • 검증: ID 목록을 만든 뒤 모든 참조 칸을 대조 (참조 무결성)
  • CSV: RFC 4180, 구분자는 첫 줄에서 가장 많은 쪽
  • 최종 스탯 = (직업 기본 + 성장 × (Lv − 1)) 보정 합/곱 → 장비·버프

검증

  • 기본 데이터는 오류·경고 없이 통과
  • 7개 테이블 CSV 내보내기 → 가져오기 왕복이 같음, 엑셀 CSV(BOM·세미콜론·따옴표·한글 머리글)
  • 없는 ID·중복 ID·빈 필수값·숫자 범위·선택지 밖 값을 행 단위로 표시, 페이즈 형식

오타 하나가 보스를 바꿉니다

스킬 시트에서 SK_SLAM을 지우면, 그 스킬을 쓰던 오크 전사와 화염 골렘 페이즈가 조용히 깨지고 전투에서는 "보스가 스킬을 안 쓴다"는 엉뚱한 증상으로 나타납니다. 데이터 테이블은 이런 깨진 참조를 전투를 돌리기 전에 칸 단위로 보여 주고, ID를 바꾸면 참조를 함께 고칩니다.
