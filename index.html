재화 흐름(경제) 시뮬레이터

재화의 획득처와 소모처를 노드로 연결하고, 유저 유형별로 일 단위 누적을 돌려봅니다. “이 이벤트를 넣으면 30일 뒤 골드가 얼마나 쌓이나”를 보는 용도입니다.

  • 입력 재화 · 획득처 · 소모처 · 교환 규칙 · 유저 유형(활동량 배수, 행동 규칙)
  • 계산 일 단위 이산 시뮬레이션 (획득 → 교환 → 고정 소모 → 비율 소모)
  • 출력 N일 보유량 추이, 소모율(누적 소모 ÷ 누적 획득), 적체 경고, 편차 띠
  • 연결 강화 계산기의 기대 비용을 소모처로 바로 가져오기
개발 예정 · 1순위

프레임 데이터 기반 패턴 검증기

보스 패턴의 선딜·판정·후딜과 플레이어 회피 무적 프레임을 넣으면, 패턴별로 회피 가능 구간과 반격 여유가 몇 프레임인지 계산합니다. “이 연계는 회피 윈도우가 6프레임이라 너무 빡빡하다” 같은 검증이 목적입니다.

  • 회피 윈도우 무적 프레임 − 판정 지속 + 1 (0 이하면 구르기로 회피 불가)
  • 반응 회피 식별 시점 + 반응 시간 ≤ 최종 회피 입력 시점 (아니면 암기 패턴)
  • 반격 여유 다음 판정 시작 − (회피 종료 + 공격 발생 + 공격 후딜 + 회피 선딜)
  • 출력 패턴별 색상 타임라인 + 판정 칩
