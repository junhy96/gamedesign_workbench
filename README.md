## 강화 기대 비용 계산기

실패 시 단계가 내려가는 강화 구조는 엑셀로 풀기 까다롭습니다. 이 도구는 이를 **흡수 마르코프 체인**으로 모델링해 정확한 값을 계산하고, 시뮬레이션으로 운이 나쁠 때의 비용까지 보여줍니다. 강화·성장 시스템 기획과 **확률 공시 수치 검증**에 쓸 수 있습니다.

### 할 수 있는 것
- 목표 단계까지 **기대 비용 · 기대 시도 횟수 · 기대 파괴 횟수 · 파괴 없이 도달할 확률**
- 비용 분포(중앙값, 상위 10%, 상위 1%)와 파괴 횟수 분포
- 단계별 “넘기기 전에 파괴될 확률”과 비용 비중
- **찬스타임**(N회 연속 하락 시 확정 성공), 파괴 감소 이벤트, 단계별 파괴방지
- **파괴방지 최적 조합 추천**: 가능한 모든 조합을 정확해로 비교
- 설정 공유 링크, JSON 내보내기/불러오기

### 계산 방법
- 상태 = (단계, 연속 하락 수). 상태별 **기대 시도 횟수 N**을 연립방정식 `(I − Qᵀ)N = e_start`으로 풉니다(가우스 소거).
  기대 비용과 기대 파괴는 모두 N의 선형 결합이라, 방정식 한 번으로 전부 나옵니다.
- 파괴 없이 도달할 확률은 파괴를 ‘실패로 종료’로 보는 별도 방정식으로 구하고, 파괴 횟수 분포는 기하분포로 정확히 계산합니다.
- 분포는 시드 고정 몬테카를로 2만 회를 Web Worker에서 돌려 구합니다.

### 검증
정확해와 시뮬레이션이 일치하는지 테스트로 확인합니다(화면의 “계산 검증” 카드에서도 실시간으로 비교).

| 메이플 프리셋, 15성 → 목표 | 파괴 없이 도달 | 기대 파괴 | 기대 시도 |
|---|---|---|---|
| 17성 | 88.1% | 0.13회 | 7.7회 |
| 18성 | 61.7% | 0.62회 | 20.8회 |
| 22성 | 11.8% | 7.49회 | 194.8회 |
| 22성 + 파괴방지(15~17성) | 19.1% | 4.24회 | 152.2회 |

> 메이플스토리 수치는 커뮤니티 정리(나무위키, 2026-10 확인)를 바탕으로 한 **비공식 참고값**입니다. 실제 확률은 공식 공지를 확인하세요. 이 프로젝트는 넥슨과 관련이 없습니다.

## 실행

빌드 과정이 없습니다. ES 모듈을 쓰기 때문에 파일을 더블클릭하지 말고 로컬 서버로 여세요.

```bash
npm run dev      # http://localhost:5173
npm test         # 계산 모듈 테스트 (Node.js 22+)
```

## 구조

```
index.html              셸(탭, 테마)
css/style.css           디자인 토큰(라이트/다크) + 레이아웃
js/app.js               탭 전환, 테마 전환
js/lib/util.js          숫자 포맷, 저장소, 공유 링크, 파일 입출력
js/enhance/model.js     계산 (DOM 없음 — 테스트 대상)
js/enhance/simulate.js  몬테카를로 (DOM 없음)
js/enhance/mc-worker.js Web Worker 진입점
js/enhance/presets.js   프리셋 데이터
js/enhance/view.js      화면
tests/                  node:test
docs/PLAN.md            전체 기획 정리
```

## 배포 (GitHub Pages)

1. 저장소: https://github.com/junhy96/gamedesign_workbench (공개)
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, 브랜치 `main` / 폴더 `/ (root)`로 지정합니다.
3. 1~2분 뒤 https://junhy96.github.io/gamedesign_workbench/ 에서 열립니다.

## 데이터와 개인정보
모든 계산은 브라우저 안에서만 실행되며 서버로 아무것도 보내지 않습니다. 설정은 이 브라우저의 localStorage에만 저장되고, 공유 링크는 설정을 URL의 `#` 뒤에 담아 서버로 전송되지 않습니다.
